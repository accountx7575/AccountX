PDF WORKFLOW PATTERNS IDENTIFIED
=================================

Pattern 1: Direct Browser Print
- Window.print() calls in: invoiceExport.tsx, SalesInvoiceViewPage, SalesInvoicesPage, SalesInvoiceCreatePage, docPrint.tsx
- Triggered from: print buttons, page headers, row actions

Pattern 2: PDF Download as Blob
- renderDocSheetToPdfBlob() generates Blob
- URL.createObjectURL(blob) creates temporary URL
- <a href={blobUrl} download="filename.pdf">.click()
- URL.revokeObjectURL() for cleanup
- Used in: QuotationsPage handleDownloadPdf, QuotationViewPage, QuotationSendPage, SalesInvoicesPage, ReportDetailPage, Gstr1/Gstr3b pages

Pattern 3: PDF Blob for Email Attachments
- renderDocSheetToPdfBlob() generates Blob
- Passed to SendDialog attachments array
- filename and build: async () => { return renderDocSheetToPdfBlob(...) }
- Used in: QuotationSendPage, SalesInvoiceViewPage SendDialog, QuotationViewPage SendDialog

Pattern 4: Element Capture to PDF
- captureElementToPdfBlob(el) - captures specific DOM element
- Used for: GSTR-1, GSTR-3B PDF attachments, SalesInvoiceViewPage PDF export
- Targets specific element by ID (e.g., #invoice-print-area, #report-print-area)

Pattern 5: Print CSS + A4 Layout
- All PDF generation uses Om-style print CSS with 8mm margins
- @page { size: A4 portrait; margin: 8mm }
- print-color-adjust: exact !important for color accuracy
- break-inside: avoid for table rows and items
- Designed for theme-independent printing

SUMMARY
=======

The project has a comprehensive PDF/print/download functionality built around:
- html2canvas for rasterizing HTML elements to canvas
- jsPDF for creating PDF documents with A4 portrait layout (8mm margins)
- A shared Om-style print CSS for consistent formatting across document types

Key document types supporting PDF generation/printing/download:
- Tax invoices (sales invoices)
- Quotations
- Purchase orders
- Purchase bills
- Sales orders
- GST returns (GSTR-1, GSTR-3B)

The core PDF generation logic is in src/lib/docPrint.tsx (939 lines) which is the most
important file, with src/lib/pdfCapture.ts (40 lines) and src/lib/invoiceExport.tsx (129 lines)
providing supporting functionality. Multiple page components use these libraries to
provide PDF export, printing, and download capabilities throughout the application.

The src/components/invoice/InvoiceSheet.tsx (295 lines) is the shared printable component
reused across invoice-related pages. Quotation and invoice systems have separate but
similar implementations using the same underlying libraries.

Duplication noted: src/pages/SettingsPage.tsx contains renderDocSheetToPdf and
renderDocSheetToPdfBlob functions that are identical to those in src/lib/docPrint.tsx,
suggesting either historical copying or separate development paths.
